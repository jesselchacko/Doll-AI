Doll
Doll is a private AI assistant built in Python using Ollama, Qwen, and SQLite.

Doll is designed to run locally, maintain user privacy, and gradually evolve into a full-featured personal AI assistant.

The project is being developed with the following goals:

Privacy-first
Local execution
No dependency on cloud AI services
Expandable architecture
Full user control
Current Features
AI Conversation
Doll communicates through a command-line interface using a locally hosted AI model.

Persistent Memory
Doll can remember information between sessions using SQLite.
